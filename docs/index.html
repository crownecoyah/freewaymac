01 / THE SCENERY

点の光がつなぐ、夜の風景。

道路のカーブと起伏、遠くの街の灯り、星空と流れ星。シンプルな光の連なりが、走り続ける風景を描きます。

03 / GET STARTED

インストール方法

  1. 上のボタンからZIPをダウンロードして展開します。
  2. FreeWayMac.saverをダブルクリックし、macOSの案内に従ってインストールします。
  3. 警告が表示された場合は、以下のGatekeeperの案内を確認してください。
  4. システム設定のスクリーンセーバー画面でFreeWayMacを選択し、動作を確認します。

Gatekeeperについて

FreeWayMacはad-hoc署名で配布しており、Developer ID署名とAppleによる公証を受けていません。インターネットから取得すると、Appleが安全性を確認できない旨の警告が表示される場合があります。これはマルウェア判定を直接意味しませんが、安全性の保証でもありません。

配布元を確認し、ご自身の判断でインストールしてください。実行する意思がある場合は、警告をいったん閉じ、「システム設定」→「プライバシーとセキュリティ」に実行許可項目が表示されていれば「このまま開く」を選択し、必要な認証と確認を行います。

この手順は一般的な案内です。OSによって表示や操作は異なり、すべての手順を各実機で検証したものではありません。詳しくはApple公式「Macでアプリを安全に開く」と同梱のREADME.txtをご確認ください。

確認されている問題

Sonoma 14.5のIntel Macで、初回自動起動時に黒画面となった事例があります。通常の操作でデスクトップへ戻り、セキュリティ警告を確認してください。実行許可後は正常に起動しましたが、原因は確定していません。

macOS 27.0.1では、プレビューやスクリーンセーバーから復帰後にオプションを再表示できない場合があります。「システム設定」を終了して再起動すると改善することがあります。

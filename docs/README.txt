FreeWayMac

懐かしのスクリーンセーバー「FreeWay」をMacで

FreeWayMacは、かつて公開されていたスクリーンセーバー「FreeWay」に着想を得て、macOS向けに新たに開発したスクリーンセーバーです。
夜空の下、どこまでも続く道路を走り続ける風景をお楽しみいただけます。
道路のカーブや起伏、街灯、星空など、オリジナルのFreeWayが持っていた独特の雰囲気を、現代のMacで再現することを目指しました。

1. 動作環境
配布物は、Apple Silicon（arm64）とIntel（x86_64）の両方に対応するUniversal Binary版です。
最低対応OSはmacOS 13.0です。

次の環境で動作を確認しています。
- MacBook Air（M2、2022年）：macOS 27.0.1（内蔵ディスプレイ＋外部ディスプレイ）
- MacBook Pro（Intel、2020年）：macOS Sonoma 14.5

Intel Macでは、SafariからのZIPダウンロード・展開、スクリーンセーバー一覧と専用サムネイルの表示、実行許可後の起動、設定の保存・維持、オプション画面の繰り返し表示を確認しました。
実行許可後は、今回視認できた範囲で繰り返し正常に起動しました。ただし、街灯・カーブ・坂道など、描画の全項目をIntel実機で詳細に検証したわけではありません。
macOS 13そのものや、上記以外のmacOSバージョン・機種・画面構成では実機確認していません。
確認済み環境以外での動作を保証するものではありません。

2. インストール方法
FreeWayMacは、Apple Developer Programに登録せずに提供している無料のスクリーンセーバーで、Developer ID署名とAppleによる公証を受けていません。
そのため、インターネットからダウンロードすると、macOSのGatekeeperによって実行が制限される場合があります。

Sonoma 14.5の実機では、次の警告が表示されました。
「“FreeWayMac.saver”が悪質なソフトウェアかどうかをAppleでは確認できないため、このソフトウェアは開けません。」
この警告は、Appleが安全性を確認できないことを意味し、マルウェアと判定されたことを直接意味するものではありません。一方、安全性が保証されているという意味でもありません。
配布元を確認し、ご自身の判断でインストールしてください。

以下は、Sonoma 14.5での実例を参考にした一般的な案内です。実機で確認した結果は、警告の表示と、実行許可後の正常な起動です。下記の操作すべてをその実機で検証したものではありません。
macOSのバージョンによって、警告文や操作方法が異なる場合があります。
　1. 配布ZIPファイルをダウンロードし、展開してください。
　2. FreeWayMac.saverをダブルクリックし、macOSの案内に従ってインストールしてください。
　3. Gatekeeperの警告が表示された場合は、いったん閉じてください。
　4. 「システム設定」→「プライバシーとセキュリティ」を開いてください。
　5. FreeWayMacの実行許可項目が表示されていれば、配布元を確認したうえで、実行する意思がある場合に「このまま開く」を選択してください。
　6. 必要に応じて管理者認証を行い、確認ダイアログが表示された場合は内容を確認して「開く」を選択してください。
　7. システム設定のスクリーンセーバー画面でFreeWayMacを選択し、動作を確認してください。

Apple公式の案内「Macでアプリを安全に開く」：
https://support.apple.com/ja-jp/102445

3. 設定
システム設定のスクリーンセーバー画面から、FreeWayMacの「オプション」を開くと、各種設定を変更できます。
主な設定項目：
- 表示間隔（15～50 ms、既定値30 ms）
- 星のスクロール
- 流れ星の表示
- 星の色・街の灯りの色
- 速度倍率（100%は原版相当）と100%へのリセット
変更した設定は「保存」で保存され、次回スクリーンセーバー開始時に反映されます。
「キャンセル」では変更を保存しません。
保存済みの設定は、システム設定の再起動後も保持されます。

4. 既知の問題
初回の黒画面（確認された事例）
Sonoma 14.5のIntel Macでは、初回の自動起動時に画面が真っ暗になりました。通常の操作でデスクトップに戻ると、安全性を確認できない旨の実行許可ダイアログが表示され、許可後は正常に起動しました。
Gatekeeperによる実行制限が関係している可能性はありますが、原因は確定していません。必ず黒画面になるという意味ではありません。
黒画面になった場合は、通常の操作でデスクトップに戻り、セキュリティ警告が表示されていないか確認してください。実行許可については「2. インストール方法」を参照してください。

オプション画面の再表示
macOS 27.0.1では、全画面プレビューやスクリーンセーバーから復帰した後、オプション画面を再表示できなくなることがあります。別のスクリーンセーバー「Brooklyn」でも同様の現象を確認しています。
この場合は、「システム設定」をいったん終了して再起動すると改善することがあります。
一方、Sonoma 14.5のIntel Macでは、今回の検証中、システム設定を再起動せずにオプション画面を繰り返し正常に開くことができました。
この違いの原因がOS、CPUアーキテクチャ、その他の条件のどれにあるかは確定していません。

5. オリジナル作品について

また、菅原芳弘様によるWindows移植版「FreeWay for Win」を、動作や視覚表現を再現する際の参考としています。
FreeWayMacは、macOS向けに新たにプログラムを作成した独立した実装です。
オリジナル版およびWindows版のソースコードを使用したものではありません。
